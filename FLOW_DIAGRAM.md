# Схема работы модуля оплаты

## Процесс оплаты подписки

```
┌─────────────┐
│ Пользователь│
│ регистрация │
└──────┬──────┘
       │
       ├─── Создается User в БД
       │    search_count = 3
       │
       ▼
┌──────────────┐
│ Поиск (1-й)  │
└──────┬───────┘
       │
       ├─── search_count = 2
       │
       ▼
┌──────────────┐
│ Поиск (2-й)  │
└──────┬───────┘
       │
       ├─── search_count = 1
       │
       ▼
┌──────────────┐
│ Поиск (3-й)  │
└──────┬───────┘
       │
       ├─── search_count = 0
       │    Показываем предупреждение
       │
       ▼
┌──────────────────────┐
│ Попытка 4-го поиска  │
└──────────┬───────────┘
           │
           ├─── Доступ закрыт
           │
           ▼
    ┌──────────────────┐
    │ Кнопка "Оформить │
    │   подписку"      │
    └──────────┬───────┘
               │
               ▼
    ┌──────────────────┐
    │ create_payment() │
    │   в ЮKassa       │
    └──────────┬───────┘
               │
               ├─── Создается платеж
               │    payment_id
               │    confirmation_url
               │
               ▼
    ┌──────────────────┐
    │ Пользователь     │
    │ переходит на     │
    │ страницу оплаты  │
    └──────────┬───────┘
               │
               ▼
    ┌──────────────────┐
    │ Пользователь     │
    │ вводит данные    │
    │ карты            │
    └──────────┬───────┘
               │
        ┌──────┴──────┐
        │             │
    Успех         Отмена
        │             │
        ▼             ▼
┌───────────────┐  ┌──────────────┐
│ ЮKassa шлет   │  │ Возврат на   │
│ webhook:      │  │ страницу     │
│payment.       │  │ ошибки       │
│succeeded      │  └──────────────┘
└───────┬───────┘
        │
        ▼
┌───────────────────┐
│ Обработка webhook │
│ в /webhook/       │
│ yookassa          │
└───────┬───────────┘
        │

        │    Создается Payment в БД
        │    active = True
        │    created_at = now()
        │
        ▼
┌───────────────────┐
│ Бот отправляет    │
│ уведомление       │
│ "Подписка         │
│ активирована!"    │
└───────┬───────────┘
        │
        ▼
┌───────────────────┐
│ Пользователь      │
│ получает          │
│ безлимитный доступ│
│ на 30 дней        │
└───────────────────┘
```

## База данных

```
┌─────────────────────┐
│      User           │
├─────────────────────┤
│ id (PK)             │
│ tg_id (UNIQUE)      │
│ username            │
│ full_name           │
│ search_count = 3    │◄─── Бесплатные попытки
│ created_at          │
└──────────┬──────────┘
           │
           │ 1:N
           │
           ▼
┌─────────────────────┐
│      Payment        │
├─────────────────────┤
│ id (PK)             │
│ user_id (FK)        │
│ created_at          │◄─── Дата активации
│ active = True/False │◄─── Активна ли подписка
└─────────────────────┘

Подписка действует: created_at + 30 дней
```

## Итоговая логика

1. **Новый пользователь**: 3 бесплатных поиска
2. **После 3 поисков**: предложение подписки
3. **Оплата**: через ЮKassa
4. **Активация**: webhook → создание Payment в БД
5. **Доступ**: 30 дней безлимитного поиска
6. **Уведомление**: за 3 и 1 день до окончания
7. **Истечение**: автоматическая деактивация
